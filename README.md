# Visual Studios

The official platform for Visual Studios recording sessions, schedule coordination, creator booking management, and staff analytics.

## Features
- **Creator Booking System**: Streamlined application form with real-time Firestore synchronization.
- **Recordings Roster**: Centralized session logbook tracking dates, creators, player counts, assigned staff, and status (Pending, Scheduled, Completed, Rescheduled).
- **Staff Control Panel**: Role-based access control (Super Admin, Admin, Staff, Creator) with real-time session management and activity logs.
- **Discord Integration**: Live guild statistics and member counts directly from the Visual Studios Discord community.

## Tech Stack
- React 18 & TanStack Router / React Start
- Tailwind CSS & Lucide Icons
- Cloud Firestore & Firebase Auth
- Vite
